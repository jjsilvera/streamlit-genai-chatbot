🤖 Chatbot Multi-Modelo (Streamlit + LangChain)

Chatbot de IA con múltiples proveedores construido con Streamlit y LangChain que permite cambiar entre diferentes modelos y proveedores de LLM desde una interfaz web sencilla.

Actualmente soporta:
* Groq
* Google Gemini
* (Próximamente) OpenAI
* (Próximamente) Ollama (modelos locales)

La aplicación incluye historial de conversación, selección dinámica de proveedor y modelo desde la interfaz.

___________

🚀 Características
* 🤖 Interfaz de chat construida con Streamlit
* 🔁 Cambio dinámico entre diferentes proveedores de IA
* 🧠 Soporte para múltiples modelos
* 💬 Historial de conversación persistente
* ⚡ Respuestas rápidas usando modelos de Groq
* 🧹 Botón para limpiar el chat
* 🔐 Uso de variables de entorno (.env) para manejar claves API
